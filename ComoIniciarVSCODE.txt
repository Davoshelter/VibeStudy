           GUÍA DE EJECUCIÓN RÁPIDA EN VS CODE - WINDOWS (VibeStudy)
================================================================================

¡Todo el entorno ya está configurado y optimizado para tu PC!

MÉTODO 1: USANDO LAS TAREAS DE VS CODE (Recomendado y más fácil)
--------------------------------------------------------------------------------
1. Presiona `Ctrl + Shift + P` en VS Code.
2. Escribe: `Tasks: Run Task` (o `Tareas: Ejecutar tarea`) y presiona Enter.
3. Elige:
   - `1. Iniciar Emulador (Ligero)` -> Abre el emulador sin consumir casi RAM/CPU.
   - `2. Instalar y Abrir App (Build & Run)` -> Compila, instala y lanza la app en el emulador.
   - `3. Ver Logs de la App (Logcat)` -> Muestra los logs y errores en tiempo real.


MÉTODO 2: USANDO TU EXTENSIÓN "EMULATE" DE VS CODE
--------------------------------------------------------------------------------
1. En la barra superior derecha de VS Code verás el icono del teléfono móvil 
   (o presiona `Ctrl + Shift + P` y escribe `Emulate`).
2. Selecciona `Medium_Phone_API_37.0`.
3. Se abrirá automáticamente con las opciones de bajo consumo ya configuradas.


MÉTODO 3: DESDE LA TERMINAL DE POWERSHELL / VS CODE
--------------------------------------------------------------------------------
--- Terminal 1: Iniciar Emulador Ligero ---
emulator -avd Medium_Phone_API_37.0 -no-audio -no-boot-anim -camera-back none -camera-front none -gpu host

--- Terminal 2: Compilar, Instalar y Abrir la App ---
.\gradlew.bat installDebug
adb shell am start -n com.david.mystudio/.MainActivity

================================================================================
* NOTA: Si acabas de aplicar las variables de entorno, REINICIA VS CODE para que
  sus terminales carguen las nuevas rutas de `adb` y `emulator`.
